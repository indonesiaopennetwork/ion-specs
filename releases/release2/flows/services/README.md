# Release 2 Services flows

Draft. Release 2 proposes one Services flow:

- [`scheme-facilitation/v1`](patterns/scheme-facilitation/v1/) — government
  social scheme application facilitation for CRC `SVC-social`, from catalogue
  publication through government decision and benefit disbursement. Draft
  reference profile, pending Services working group review.

The flow uses only the eight Services packs in
[`schema/extension/services`](../../schema/extension/services/) and the shared
policy registry.
