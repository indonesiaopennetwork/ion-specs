# LogisticsContract v1

This pack carries durable agreement-level facts that are not already owned by
core Contract members. It provides typed relationships, invoice preferences,
cargo insurance, repeatable cases, cross-border terms, Indonesian customs
compliance, and a normalized cancellation record.

Raw telemetry, payment movement, tax amounts, issued-document bodies, and
imperative reverse-logistics work are kept on their owning Performance,
Consideration, Settlement, Document, or child Contract artifacts.
