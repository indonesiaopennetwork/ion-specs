# LogisticsPerformance v1

This pack is the durable shipment-execution aggregate attached to core
Performance. It records routes, milestones, alerts, assignments, proofs,
measurements, delivery attempts, warehouse execution, SLA evidence, and
sustainability evidence.

Core Performance owns identity, current status, and Commitment links. Live
location, live ETA, credentials, and refresh guidance remain in
`LogisticsTracking`. Financial attribution remains in Consideration and
Settlement.
