# LogisticsOffer v1 overview

`LogisticsOffer` separates service definition, rating inputs, negotiation,
pickup, schedules, capacity, execution support, COD, warehouse, Ro-Ro,
cross-border, SLA, and policy references into typed components.

The ION layer adds Indonesian administrative pricing zones, calendars, and IDR
cash denominations. Flow specifications decide which components are mandatory
for each logistics pattern.
