# LogisticsPerformanceStates

`LogisticsPerformanceStates` is the versioned ION Logistics execution-state
registry. It lives with the flow specifications because it describes pattern
and variant execution, not the shape of a protocol message. It is not an
OpenAPI attribute pack and has no Beckn attachment point.
Its state codes are carried by the open code on core `Performance.status`.

Version 1 is in [`v1/`](v1/README.md).
