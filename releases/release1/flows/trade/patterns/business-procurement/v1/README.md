# Trade Business Procurement Pattern v1

This Release 1 flow covers registered-business wholesale purchases with minimum
order quantities, bulk quotes, buyer purchase-order references, Faktur Pajak
preferences, upfront payment, and standard physical-goods fulfilment.

All required objects already exist in the Release 1 Trade and common packs. The
source pattern's stale pack names were reconciled, and no root schema migration
was necessary. Credit procurement, tenders, updates, reconciliation, and
Logistics-sector contracts are outside this prepaid flow.

See [`pattern.yaml`](pattern.yaml) for step requirements and
[`docs/01-happy-path.md`](docs/01-happy-path.md) for the sequence.
