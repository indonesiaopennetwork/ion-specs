# During Transaction — Overview

Apply these requirements in addition to the selected parent pattern's fields for
the same Beckn step. Multiple compatible sub-branches may be active together;
for example, fulfilment-mode selection can accompany BAP-collected prepayment.

Each included sub-branch stays within the parent transaction and uses only the
pinned Beckn request/callback pairs. See [`variant.yaml`](../variant.yaml) for
field requirements and excluded-source behavior.
