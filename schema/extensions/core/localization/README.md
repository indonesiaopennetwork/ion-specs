# core/localization

Localised text pattern for multilingual product names and descriptions. Supplies the mandatory Bahasa Indonesia `name.id` field for all resources.

**Attaches to:** `Resource.resourceAttributes, Provider.descriptor`  
**Applicable to:** All sectors
