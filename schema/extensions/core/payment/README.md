# core/payment

Payment method declarations for all ION payment rails — QRIS, VirtualAccount, EWallet (10 providers), CashOnDelivery, BankTransfer, BISettlement (BI_FAST/RTGS/SKN), BNPL, CardPayment.

**Attaches to:** `Settlement.settlementAttributes`  
**Applicable to:** All sectors
