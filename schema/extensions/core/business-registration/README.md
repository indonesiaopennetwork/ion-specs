# core/business-registration

Indonesian business registration identity — NPWP (tax), NIB (business licence), NIK, PKP VAT status, legal entity name. Mandatory for all network participants.

**Attaches to:** `Provider.providerAttributes, Contract.contractAttributes`  
**Applicable to:** All sectors
