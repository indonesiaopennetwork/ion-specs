# core/raise

Network dispute escalation tickets raised by a network participant to ION. Covers NP-to-NP and NP-to-ION escalation — distinct from consumer support tickets.

**Attaches to:** `ION network channel (/raise endpoints)`  
**Applicable to:** All sectors — post-fulfilment
